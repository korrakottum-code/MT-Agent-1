## ทำเกินแผน (ไม่มีในคู่มือ แต่มาจาก pain point จริง)

บุคลิกและชื่อเล่น "แงว" ระดับองค์กร · ความจำบทสนทนา 30 ข้อความต่อแชท · ความต่อเนื่องข้ามแชท ·
DM ตอบโดยไม่ต้องแท็ก · เอ่ยชื่อแล้วโมเดลตัดสินใจเองว่าจะตอบหรือเงียบ · อ่านรูปภาพ ·
ตั้งเตือนตามเวลา · ADMIN จัดการพนักงานผ่านแชท · ดึงชื่อกลุ่มจาก LINE อัตโนมัติ ·
**อ่านไฟล์เอกสาร PDF / Word / Excel / CSV / ข้อความ** · ตอบแบบอ้างข้อความต้นทางในกลุ่ม (quoteToken) ·
**ชุดข้อสอบอัตโนมัติ 11 ข้อ** (กันบั๊กเดิมกลับมา รันทุกครั้งที่ push)

## ค้างอยู่ / ต้องทำต่อ

1. ผูกบัญชี "แพรว" ที่ยังเป็น `pending:` เข้ากับ LINE จริง (ใช้ tool `link_user` เมื่อเจ้าตัวเข้ากลุ่ม)
2. โหมดโต้ตอบโดยไม่ต้องแท็ก — ออกแบบไว้แล้ว รอตัดสินใจว่าจะเอาแค่ขั้นที่ไม่มีค่าใช้จ่าย
   (คน reply ใส่ข้อความบอท / บอทเพิ่งพูดแล้วคุยต่อ) หรือเปิดโหมดฟังทั้งกลุ่มเป็นรายกลุ่มด้วย
3. MVP 0.3 ที่เหลือ: สรุปความรู้ข้ามกลุ่ม และทำดัชนีเอกสารที่ส่งเข้ามา (ควรรอข้อมูลจริงสะสมก่อน)
